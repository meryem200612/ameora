# 💎 Ameora — Jewelry E-commerce

Ameora is a modern e-commerce web application dedicated to jewelry and accessories.
The project provides an online shopping experience with product browsing, categories, authentication, cart management, and order management.

## 🚀 Features

* 🛍️ Product catalog
* 💎 Jewelry categories: necklaces, bracelets, earrings and rings
* 🔎 Product search and filtering
* 🛒 Shopping cart
* 👤 User authentication
* 📦 Order management
* ❤️ Wishlist
* ⭐ Product reviews
* 🛠️ Admin dashboard
* 📱 Responsive design

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/meryem200612/ameora.git
cd ameora
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend

```bash
cd backend
composer install
```

Create your `.env` file and configure the MySQL database.

```bash
php artisan migrate
php artisan serve
```

## 🎯 Project Goal

The goal of Ameora is to create a complete and modern e-commerce platform while applying full-stack development concepts such as REST APIs, authentication, database management, CRUD operations, and responsive UI design.
